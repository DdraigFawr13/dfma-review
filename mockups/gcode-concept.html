G-code

    Practices the code follows

    • Safe start block each program: inches, absolute, XY plane, cancel cutter and length offsets and canned cycles (G20 G90 G17 G40 G49 G80).
    • Tool change and length offset: T1 M6, then G43 H1 before the first Z move, so the machine knows the tool's length.
    • Rapids clear of the part: G0 to a safe height (0.5 in) first; feed only below the clearance plane (0.1 in).
    • No straight plunge with an end mill: it ramps in along the pocket's centre line.
    • Climb milling: counter-clockwise inside the pocket, which is the cutter-on-the-left side of the wall with a clockwise spindle.
    • Depth in steps: two passes of 0.125 in (half the tool diameter), then a finishing lap at full depth.
    • Peck drilling for the hole (G83, 0.100 in pecks): depth 3 × diameter clears chips.
    • Safe end: coolant off, spindle off, back to the tool-change height (G28), program end (M30).
