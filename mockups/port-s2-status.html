What was measured

  • Quick set: the browser engine gives the Python app's answer on 77 of 77 files, now including holes. That covers 1,105 holes, 379 hole findings and 3,022 passed checks. Before the port, 69 of the 77 differed.
  • Full set: 290 files. 282 are the same. 6 crash the Python app (old UMD files). 2 differ only in the 3D mesh, on the same 3 faces as in S1. No hole, finding or row differs on any file.
  • Tests: 926 service, 44 web, 78 service-page and 28 browser-copy tests pass.
  • A fresh review compared the port with the Python code line by line. It found 8 items, and 7 are fixed. One was a gap from S1: two rounding test cases sat inside a comment and never ran. One was a tie-break that followed a different order from Python's. The eighth is a number-format corner case no S2 value reaches, now recorded as a limit.
