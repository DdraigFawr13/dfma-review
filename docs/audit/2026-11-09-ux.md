## Other findings

### F1 Decision ids and file names shown to users

- **Rework if left:** medium
- **Effort:** S
- **Evidence:** `service/dfma/settings.py:32` "25.4 times too small (D-020)"
- **Case:** The no-unit warning on the Part step ends "(D-020)"; an inside groove's setup note says "Protolabs does not, D-026" (web/src/findings.ts line 230); the PDF's cost note names config/drivers.toml (web/src/report.ts line 145). A shop manager can't open a decision id or a toml file, and rows.py's header promises none on screen.
- **Fix:** Drop "(D-020)", ", D-026" and "(config/drivers.toml)" from the text; keep them in code comments.

### F2 One check under three names: short title, check name, PDF name

- **Rework if left:** medium
- **Effort:** M
- **Evidence:** `web/src/report.ts:230` "RULE_NAMES[f.rule] ?? f.rule"
- **Case:** The same rule reads "Deep hole" on a row, "Hole depth check" under it and in Report > Rules run, and "hole depth" in the PDF finding header (RULE_NAMES in web/src/findings.ts, itself mixed case: "Hole feature vs hole"). A reader can't tie the PDF page or the Rules run list to the row.
- **Fix:** Head each PDF finding page with the row's short title and check name; drop RULE_NAMES.

### F3 Error messages say what is wrong, not how to fix it

- **Rework if left:** medium
- **Effort:** S
- **Evidence:** `service/dfma/settings.py:27` "This is not a STEP file this tool can read"
- **Case:** Six service errors (not STEP, no solid, over 50 MB, took too long, .ipt too large, no 3D model in the .ipt) end without a fix; the only fix shown is "Choose another file, or try again." (web/index.html line 77), and "try again" does nothing for a refused file. The app-not-running message (web/src/api.ts line 225) asks a shop manager to run a terminal command. The error also sits under Process and Material, away from the file button, and focus doesn't move to it (ux-1440-error.png).
- **Fix:** Add one clause per message ("Export it again as .step or .stp from your CAD.", "Export a single body or a smaller part."); show "try again" only for timeouts and network errors; place the error under the STEP file field with aria-describedby.

### F4 Open row detail breaks at 200% text
